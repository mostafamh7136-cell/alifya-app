# Alifya — أليفا

Interactive Arabic learning app built with Next.js, TypeScript and Tailwind CSS.

## What is included
- Arabic lessons with practical vocabulary and quizzes
- Client-side progress, XP, streaks and best scores
- Responsive RTL interface for mobile and desktop
- Search and lesson filtering
- SEO metadata, Open Graph data, sitemap, robots and web app manifest
- Resilient loading and 404/error states
- Lightweight production security headers

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```

The Vercel project is configured to deploy from this repository's `main` branch.
